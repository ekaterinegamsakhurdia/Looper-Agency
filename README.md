# Looper Agency site

Open the folder in VS Code, install **Live Server**, right-click `index.html` → *Open with Live Server*.

* `js/config.js` — image paths (hero card fronts `01–10.jpg`, shared card back `back.jpg`, 9 service hover images)
* `images/partners/` — 12 partner logos (`01` … `12`, png/svg/jpg/webp) for the Partners collage
* `images/cards/`, `images/services/`, `images/branding/` — drop your pictures here
* `careers/*.html` — one detail page per open role (opened from the Careers section). To add a role, copy one of these files, edit the text, and add a card in the Careers section of `index.html`
* `css/styles.css`, `js/main.js` — styles and behaviour
* Add `#edit` to the page address to show the image-upload helper buttons (hidden for visitors)
